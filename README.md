# ML Kit Image Recognition App

##  Description
A Flutter app that uses Google ML Kit to perform image labeling and object recognition from camera and gallery images.

## Features
- Capture image using Camera
- Select image from Gallery
- Detect objects using ML Kit
- Show confidence percentage

## Technologies Used
- Flutter
- Dart
- Google ML Kit

##  How to Run
flutter pub get  
flutter run  

##  Dependencies
- google_mlkit_image_labeling
- image_picker
